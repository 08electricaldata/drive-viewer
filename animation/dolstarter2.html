📘 How it works

1. READY: Control/protection permissives are healthy and no trip is active.
2. START: In LOCAL, the local START command is used. In REMOTE, the simulated PLC/DCS command is used.
3. K1: The contactor coil is energized; its main contacts close and the motor receives full line voltage.
4. HOLD: A typical DOL control circuit uses an auxiliary holding contact so the contactor remains energized after START is released.
5. FEEDBACK: RUN/READY/TRIP status is represented as PLC/DCS signals. Current is shown through the simulated transducer.
6. STOP/TRIP: STOP or a protection trip de-energizes K1 and removes motor power.
